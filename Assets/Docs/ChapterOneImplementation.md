# 챕터 1 — 빈손 (유아기)

적용 씬: `Assets/Scenes/FirstScene/FirstMap.unity`

기준: [Notion 스토리](https://www.notion.so/3d062d4b67b08007be11c7f671da929d). 아이템 표와 획득 순서가 다른 부분은 상세 퍼즐 설명을 우선했다. 현재 프로젝트의 그림을 재사용하고, 없는 그림은 교체하기 쉬운 임시 오브젝트로 표시했다.

## 진행 및 조작

1. 빈 가방으로 시작한다. 부모의 도입 대사 후 양옆 화살표로 방을 돌아본다.
2. 큰 상자를 밀면 잠긴 상자와 토끼 인형이 드러난다.
3. 작은 구멍을 클릭해 확대한다. 숫자 **2413**을 확인하고 ESC로 돌아와 상자를 연다. 곰 인형과 길 A를 얻는다.
4. 가방 오른쪽 위 장착칸에 인형을 놓은 뒤 테이블을 클릭한다. 왼쪽은 곰, 오른쪽은 토끼다. 비밀 서랍에서 길 B를 얻는다.
5. 빨강·초록·갈색 책을 모아 가방 첫 줄 왼쪽 세 칸에 순서대로 놓는다. 책장 아래 길 C가 나온다.
6. A·B·C를 가방에서 가로로 이어 조합한다. 완성된 길은 3×1이며 해체 후 재조합할 수 있다.
7. 완성된 길을 장착하고 공 굴리기 장치에 사용한다. 공이 끝에 도달하면 고양이 인형과 핑크 공을 얻을 수 있다.
8. 고양이를 장착해 부모에게 전달하고, 핑크 공을 챙긴 뒤 출구를 클릭한다.

물건 클릭, 가방 버튼, 인벤토리 R 회전, ESC 닫기, F5 저장/F9 불러오기는 기존 조작을 사용한다. 필수 아이템은 버리기를 막아 진행 불능을 예방했다. 가방 용량은 기존 10×10을 유지한다.

출구는 기존 **BaseMap**으로 연결한다. 별도 챕터 2 씬/콘텐츠는 아직 없으며 이번 구현에 포함하지 않았다. 핑크 공은 인벤토리에 남아 다음 씬으로 이동한다.

## 구현 및 유지보수

- 생성 콘텐츠는 씬의 `Chapter01` 아래에 배치했다. 기존 테스트 배치와 대화 루트는 비활성화했다.
- `Editor/ChapterOne/ChapterOneSceneBuilder.cs`의 메뉴 `Tools > Bag to the key > Apply Chapter 1 to FirstMap`으로 재생성한다. **이 메뉴는 Chapter01 내부의 수동 변경을 덮어쓴다.** 아트 교체를 유지하려면 빌더의 참조도 함께 바꾼다.
- 작업 시작 시 씬 사본을 프로젝트 `Temp/ChapterOneBackup/FirstMap.before-chapter1.unity`에 보관했다. Temp는 장기 백업용이 아니다.
- 상태는 기존 `GameProgressState`의 `ch01.*` ID와 기존 저장 시스템을 사용한다. 동일 씬의 이전 세이브를 불러올 때 습득물과 보상 표시를 복원한다.
- 인벤토리 UI는 씬을 넘어 유지되므로 방 회전 버튼은 현재 씬의 카메라를 찾는다. 책 배치 퍼즐은 중복 인벤토리가 제거된 다음 프레임에 다시 연결한다.
- FirstMap의 현재 GUID를 Windows 빌드 프로필과 전역 씬 목록에 반영했다.
- 한국어 폰트의 단일 아틀라스 용량을 초과해 일부 글자가 네모로 표시되던 문제는 다중 아틀라스를 켜고 챕터 문자를 미리 추가해 수정했다.
- 에디터 제어를 위해 `com.unity.pipeline` 패키지를 추가했다. 런타임 챕터 로직은 CLI에 의존하지 않는다.

## 검증 범위

Unity 6000.4.2f1의 Play Mode에서 컴포넌트의 실제 동작 메서드를 호출해 검증했다. 별도 플레이어 빌드 및 모든 입력을 마우스로 수행하는 수동 완주까지 검증한 것은 아니다.

- 빈 인벤토리 시작, 상자 이동과 토끼 노출
- 오답 암호 거부, 정답 해제, 구멍 확대/복귀
- 잘못된 인형 자리 거부, 정상 배치와 아이템 소모
- 책의 잘못된 배치 미완료/정상 배치 완료
- 길 조합·해체·재조합, 장착과 사용
- 공 이동 완료, 고양이 전달, 핑크 공 없는 출구 차단
- 필수 아이템 버리기 거부
- 프로젝트 Temp의 별도 중간 저장 파일로 복원 및 습득물 재획득
- BaseMap 전환과 완료 상태/핑크 공 유지
- FirstMap 재진입 후 책 배치 이벤트 수신과 회전 버튼 동작, 인벤토리 중복 없음
- 최종 플레이 검증의 Console 오류 0건, 코드 변경의 공백 검사 통과

검증 중 사용자 저장 슬롯을 사용하지 않았고 자동 저장을 일시 제외했다. 최종 씬에는 원래 자동 저장 설정을 복원한다.
